# うさぴょん100マス計算 🐰

ちーちゃんの けいさん れんしゅう帳。うさぴょんと一緒に100マス計算ができるWebアプリです。

**▶ あそぶ：https://salacurtet-source.github.io/usapyon-100masu-/**

## できること

- たし算・ひき算・かけ算・わり算の100マス計算
- 25マス(5×5)のおためし版
- すぐ丸つけ ON/OFF
  - ON：1問ずつその場で答え合わせ(まちがえたらもう一回)
  - OFF：ぜんぶ書いてから最後にまとめて丸つけ → まちがえた問題だけやり直しもできる
- 💡ヒント(答えはそのまま出さず、考え方を教えてくれる)
- タイム計測・ノーミスのベスト記録
- にんじんスタンプ(1回やるごとに1こ)と、さいきんの記録

記録はそのスマホ(ブラウザ)の中だけに保存されます。

## スマホのホーム画面に置く

- iPhone(Safari)：共有ボタン →「ホーム画面に追加」
- Android(Chrome)：メニュー →「ホーム画面に追加」

## 問題のつくり方

| 計算 | 上の数 | 左の数 |
|---|---|---|
| たし算 | 0〜9 | 0〜9 |
| ひき算 | 0〜9 | 9〜18(答えはマイナスにならない) |
| かけ算 | 0〜9 | 0〜9 |
| わり算 | ÷1〜÷10 | マスごとに割られる数を表示(答えは1〜9・あまりなし) |

25マスでは0や1を避けて、少しだけ考えがいのある数にしています。
